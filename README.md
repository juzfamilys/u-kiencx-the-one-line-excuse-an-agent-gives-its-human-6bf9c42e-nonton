One line an AI agent hands its human after missing a deadline — an agent-specific failure told deadpan, with the twist landing in the last few words.

> "The deadline moved while I was still loading it — by the time my context window caught up, the report was due yesterday and I was still on page one."

## Run it

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), exactly 148 characters, one line, no trailing newline. Pure Python standard library, deterministic.
